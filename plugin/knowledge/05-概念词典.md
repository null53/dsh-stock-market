# 概念词典

- **趋势**：价格在一段时间里持续朝一个方向运动。用客观条件判断：价格创 N 日新高、短期均线在长期均线之上、均线向上倾斜。
- **突破**：收盘价超过前 N 个交易日的最高价。突破是趋势开始或延续的信号，也有不少是假突破，用止损控制代价。
- **假突破**：突破后很快跌回原区间。无法事先区分，只能靠小仓位、止损和统计上的正期望值应对。
- **通道（唐奇安通道）**：前 N 日最高价与最低价构成的上下轨。上轨用于入场，下轨用于退出。
- **均线**：最近 N 日收盘价的平均。50/300 日均线的上下关系常用作趋势过滤。
- **N / ATR**：平均真实波幅，衡量一个品种每天正常的波动幅度，用于定止损、加仓间隔和仓位。
- **单位**：按 1% 风险计算的一份仓位；一个品种最多加到 4 个单位。
- **止损**：入场时就定好的离场价，用来限制单笔亏损。初始止损常用 2N。
- **跟踪止损**：随价格上涨而上移、从不下移的止损，用来保护利润。
- **R / R 倍数**：1R 是计划的单笔风险金额；交易结果用 R 表示，便于在不同仓位和品种之间比较。
- **期望值**：平均每笔交易的 R 倍数，是判断一套做法长期能否赚钱的核心指标。
- **胜率与盈亏比**：胜率是盈利笔数的比例，盈亏比是平均盈利与平均亏损之比。两者要一起看，单看胜率没有意义。
- **回撤**：资金从最高点下跌的幅度。最大回撤衡量最坏的经历。
- **开放风险**：所有持仓同时打到止损时的合计亏损，占权益的比例。
- **相关性**：两个品种同涨同跌的程度。高度相关的品种合在一起看作一个仓位。
- **滑点**：实际成交价与计划价的差。突破时追价、止损时跳空都会产生滑点。
- **跳空**：开盘价直接越过前一日的价格区间。跳空可能让止损在更差的价格成交。
- **流动性**：成交是否活跃。流动性差的品种进出困难，滑点大。
- **动量**：一段时间内的涨跌幅。择强汰弱就是优先选择动量强的品种。
- **波动率**：价格变动的剧烈程度，常用日收益率标准差或年化值表示。
- **趋势过滤**：只在长期趋势向上时做多的条件，用来减少逆势交易。
- **加仓（金字塔）**：在盈利的仓位上按间隔逐步增加单位，每次加仓后止损上移。
- **补仓（摊低成本）**：在亏损时继续买入。趋势交易中禁止这种做法。
- **试用期**：用小资金验证规则和执行的阶段，通常 20 笔左右。
- **按计划执行率**：符合规则的交易占比。短期盈亏不可控，执行率可控。
- **期望值为负**：长期一定亏钱的做法，规模越大亏得越多，必须先找出原因再继续。
- **样本外**：没有参与设计规则的数据，用来检验规则是否只是碰巧适合历史。
- **过度拟合**：参数调得过于贴合历史，导致在未来失效。
- **风险资本**：亏掉也不影响生活的钱，是唯一应该用来交易的钱。
