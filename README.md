# 市场 · DSH 插件

[DeepSeek Harness](https://github.com/deepseek-ai)（DSH）左侧栏插件：A 股、ETF/LOF、港美股和场外基金行情，海龟量化信号、模拟盘、实盘跟踪、规则选股、提醒，以及内置交易规则库的 AI 顾问。

当前版本：**v0.6.5**（2026-11-16）

## 安装（推荐：通过插件索引，之后可以一键更新）

1. 打开 DSH 的 **插件**，在 **实验性插件** 里打开 **自定义插件索引**。
2. 进入 **发现** → **索引源** → **添加索引源**，粘贴下面的地址：

   ```
   https://null53.github.io/dsh-stock-market/index.json
   ```

3. 在「发现」里搜索 **市场**，点 **安装**，按提示启用，然后重启 DSH。左侧栏会出现「市场」图标。
4. 以后有新版本时，「市场」页面顶部会提示；到 **插件 → 发现**，在「市场」上点 **更新**，完成后重启 DSH。

## 直接用 Git 地址安装

在 **插件 → 添加插件** 里输入：

```
git+https://github.com/null53/dsh-stock-market.git
```

这种方式装上的插件没有「更新」按钮，换新版本需要先卸载再安装。推荐用上面的插件索引。

## 功能

- **行情**：A 股（沪深北）、ETF、LOF、港股、美股、场外基金；分时、日/周/月/60 分 K 线，滚轮缩放、拖动平移；K 线上悬停查看当天的新闻、公告和事件。
- **量化信号**：海龟系统 1/2 状态、50/300 日趋势过滤、N 与 2N 止损、1% 风险头寸单位、概率区间，以及这只证券自己历史上同类信号的统计。
- **模拟盘**：按 A 股规则（T+1、100 股一手、涨跌停、手续费）。
- **实盘跟踪**：插件不下单。先按你能承受的亏损给出起步资金；买前给出计划单（数量、止损、逐项检查）；之后提醒止损、退出、加仓、回撤；按 R 倍数统计并让 AI 复盘出你的个人交易规则。金额和股数只保存在你的电脑上，发给 AI 的只有比例和 R 倍数。
- **规则选股**：海龟 55/20 日突破、强势趋势、ETF 趋势、场外基金趋势。
- **AI 顾问**：针对当前证券、选股结果或整体市场多轮对话，给出明确的买卖倾向、止损位和仓位。使用你在 DSH 里配置的 DeepSeek 模型。
- **智能体工具**：在任何 DSH 对话里都能调用 `market_*` 工具查行情、做分析、看实盘待办，以及用 `trading_knowledge_search` 查交易规则。

## 说明

- 安装和更新需要能访问 GitHub。
- 行情来自东方财富、腾讯、新浪的公开接口，可能延迟或限流，插件会自动切换数据源。
- 数据保存在 `~/.dsh/plugin-data/stock-market/`；关闭插件即停止所有轮询。
- 内容仅供参考，不构成投资建议。

# 使用说明

左侧栏「市场」：行情、量化信号、模拟盘、实盘跟踪、选股、提醒和 AI 顾问。

## 使用

- **行情**：顶部是主要指数；「行情」页切换 A股 / 沪A / 深A / 创业板 / 科创板 / 北交所 / ETF / LOF / 港股 / 美股 / 场外基金，点列头排序，点名称打开右侧详情。搜索框支持代码、名称、拼音和基金名。
- **详情**：分时、日K、周K、月K、60分图表，K 线上滚动鼠标滚轮缩放时间区间、按住拖动平移、双击复位；「量化信号」显示海龟系统 1/2 状态、趋势过滤、N、2N 止损和头寸单位；「概率区间与历史统计」显示 5/20 日价格区间和这只证券历史上同类信号的表现。
- **新闻与事件**：K 线上的彩色圆点表示当天有新闻、公告或事件，鼠标悬停查看；点击 K 线固定当天，可以「让 AI 分析这天为什么涨/跌」。详情页的「新闻、公告与事件」点标题即可在新窗口打开原文。
- **AI 顾问**：在详情底部直接提问，比如"现在能买吗？"。回答会给出明确倾向、止损位、仓位和依据（插件内置的交易规则）。「转到 DSH 对话」把问题带进完整的智能体会话。标题下方可以选模型和推理强度（列表来自 DSH 当前的模型目录，新模型点 ↻ 就会出现）。
- **模拟盘**：详情里点「模拟交易」下单（A 股规则）；「模拟盘」页查看持仓、设置止损、撤单、看权益曲线。
- **实盘**：插件不下单。第一次打开「实盘」先回答几个问题，得到建议的起步资金和单笔风险；之后在证券或基金详情点「记录实盘」，先看计划单（数量、止损、逐项检查），在券商或基金 App 成交后再录入。「实盘」页列出待办（止损、退出、加仓、上移止损、回撤），紧急的会在左侧栏图标显示红点；平仓后在交易日志里标记是否按计划，「让 AI 复盘」生成你的个人交易规则。金额和股数只存在本机，发给 AI 的只有比例和 R 倍数。
- **选股**：选一个方案后点「开始选股」，结果可以「让 AI 点评这批候选」。「场外基金趋势」专门筛场外基金，走势几乎一样的（比如各家公司的同一指数基金）合并成一组。在「AI 顾问」里直接问"有哪些基金适合买"也会自动跑选股，再从候选里给建议。
- **提醒**：详情里点「设提醒」；触发后在「提醒」页和左侧栏图标的小红点显示。
- **聊天里使用**：在任意 DSH 对话里可以直接问行情，智能体会调用 `market_*` 工具。

## 说明

- 行情来自东方财富、腾讯、新浪的公开接口，可能延迟或限流；插件会自动切换数据源。
- 每次向 AI 顾问提问会消耗一次 DeepSeek 模型请求。
- 数据保存在 `~/.dsh/plugin-data/stock-market/`。关闭插件后停止所有轮询。
- 内容仅供参考，不构成投资建议。
